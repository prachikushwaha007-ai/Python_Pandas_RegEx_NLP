# Python for Digital Humanities & Historical Text Processing

This repository documents my learning journey, practice scripts, and data manipulation projects focused on applying **Data Science** and **Natural Language Processing (NLP)** techniques to historical texts and Digital Humanities.

---

## 📌 Key Highlights & Skills Covered

- **Data Wrangling (Pandas):** Structuring, querying, cleaning, and analyzing historical datasets.
- **Pattern Matching (RegEx):** Cleaning up OCR garbage and patterns from unstructured texts (including CIA historical documents).
- **Natural Language Processing (NLP):**
  - **spaCy:** Extracting Named Entities (NER) on "Alice in Wonderland" text. 
  - **NLTK:** Text tokenization and structural analysis practice.
- **Geospatial Mapping (Folium):** Interactive map visualizations using spatial Python libraries.
